- **Bundle Checks Must Be Quote-Tolerant:** `build.mjs` bundles with esbuild (IIFE, non-minified), which re-emits every string literal with DOUBLE quotes. Any `tools/verify-bundle.mjs` check that matches string contents must use a `['"]` character class (or quote-agnostic regex), never a hardcoded single-quote `s.includes(...)`. Also: a key code like `KeyT` may legitimately appear in the bundle as a *default bind* — negative "stale hotkey" checks must target the specific hotkey expression (e.g. `e.code !== 'KeyT'`), not the bare code. esbuild also re-emits default-exported classes as `var Name = class` (never `class Name`), moves trailing comments onto their own line, and normalizes object-literal spacing — so `verify-bundle.mjs` regexes must match structural tokens (e.g. `/Crosshair\s*=\s*class/`, `def:\s*64`), never source formatting.
