## 1. Behavior spec (user-confirmed)

### Spaceshuttle (wave enemy, 17th species)
- Spawn **off-screen right** (`x = viewW + 140`) at a fixed flight altitude (hover band `y = 80–180`).
- Pixel art **faces left** → first pass is **right → left**, sprite un-mirrored.
- Fly horizontally left at the current config-driven speed (`s * dt * 0.85`).
- When **fully off-screen left** (`x < -(60 + radius)`), flip: `strafeDir = +1` and **mirror the sprite** (`ctx.scale(-1, 1)`).
- Fly right; when **fully off-screen right** (`x > viewW + 60 + radius`), flip back to `-1`.
- **Loops forever until destroyed** — it is a wave enemy and waves only clear when `game.enemies.length === 0`, so it must keep coming back (no despawn).
- Keep: eased banked tilt (`strafeDir * 0.22`), telegraphed aimed cannon fire (0.4s red sight ring), shield/boss bar, sprite + procedural fallback.

### Spaceballs One (easter-egg ship)
- **One-way flyby — NO flip, NO return.** Spawn **off-screen bottom-right**, race diagonally **up and left**, despawn cleanly once fully off-screen top-left.
- Keep: 400 px/s speed, unstoppable sweep, brake-light bolt stream, treasure-chest jackpot, 6% per-wave roll (max 2/mission), dev force-spawn button.
- Art auto-rotates to heading (`SpaceballsOneArt.js` draws at `ship.heading`) → **no art code changes**, only header comment wording.

## 2. Critical code findings (why the changes look like this)

1. **`EnemyBase.update()` line 102 culls off-screen enemies:**
   ```js
   } else if (this.y > this.game.H + 80 || this.x < -80 || this.x > this.game.W + 80) {
     this.escaped = true;
     this.alive = false;
     return;
   }
   ```
   A shuttle spawning at `viewW + 140` would be deleted on frame 1, and its off-screen flip would kill it mid-turn. → **`noEscape` exemption flag** (set by the shuttle only).
2. **`baseX` is unused by ShuttleEnemy** (only other species use it) → safe to override `this.x`/`this.y` in the ShuttleEnemy constructor after `super(opts)`.
3. **`Entity.update()`** (base) only integrates `vx`/`vy` (both 0 for the shuttle — it moves via `this.x` directly) and decrements `stunTimer` → headless `update()` tests are safe with a trivial mock game.
4. `SpaceballsOne` module version is **not** in `EXPECTED_MODULE_VERSIONS` (only the modules listed in `01-version-sync.mjs` line 63) — its header version bump is cosmetic.
5. `01-version-sync.mjs` does **not** track `EnemyBase` — no entry needed there.
